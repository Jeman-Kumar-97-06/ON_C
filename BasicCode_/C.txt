Language Tranlators:
    Assembler:
        * Converts Assembly Language to Machine Code/ Object Code.
    Compiler:
        * Converts the full code snippet to object code and creates an executable/ output file to run.
        * Efficient.
        * Since it converts the whole fucking thing, it's hard to find bugs
    Interpreter:
        * Executes each line and goes to the next line.
        * Slow
        * Easy to debug.

Features Of C: 
    * High Level Language
    * Small Language with 32 keywords.
    * Many languages depend on C.
    * Machine Independent.
    * Platform Dependent.
    * Structured Language.
    * Can use this code to access memory with pointers
    * Quick and Efficient.
    * Supports Dynamic Memory Allocation.
    * Case Sensitive A != a

Structure of C Program : 
    * Comments start with '//'
    * Multiline comments go between '/*' and '*/'
    * Link Section: What shit to include ? 
        Ex : #include <stdio.h> at the top --> includes stdio.h header file.
             stdio.h --> has standard input/ output functions. 'printf' and 'scanf'.
    * Definition Section: Includes all constants.
        Ex : #define PI 3.14 --> This is called a Macro Definition.
    * Global Variable Declaration Section : 
        Ex : int a --> put outside of all functions in a snippet.
    * Mandatory - Main function section. --> Only one main function for one snippet.
        * Main functin has Declaration(Local Variables) and Executable part (Logic).
        * Control always goes to main function. Program executes from there.
    * Sub Program Section : 
        * Optional User defined functions.
        * These go after 'main' function.

Execution process of C program: 
    * Preprocessor Directives : --> any line of code that starts with '#'.
    * When you run a c code snippet, the Preprocessor first takes care of the preprocessor directives.
        Ex: #include <stdio.h> --> this will be replaced by all the shit inside stdio.h
            #define PI 3.14 -----> all instances of PI will be replaced with 3.14
    * Now a new file with '.i' extension will be created with the expanded source code.
    * This file will be compiled and an '.asm' assmbly file will be created.
    * This file will be converted to '.obj' file with the help of an assembler.
    * Then, the Linker will link the '.obj' file with the system libraries. Now, a '.exe' or '.out' file will be created.
    * Now when you run .exe or .out file, it will be loaded to the memory and then it will run.

Constants in C : 
    * You can't change these values.
    * #define PI 3.14
    * Two Types of Constants : Numeric (Integer Constants & Floating/Real Constants) and Character (Single char and String) Constants.
    * Integer Constants : 10, 4, 1, 0
        * Decimal Constants : 0-9 * 05 not allowed --> 05 is octal constant. Decimal constants with digits more than 1 shouldn't start with 0
        * Octal Constants : 0-7
        * Hexadecimal Constants : 0-9, A-F --> starts with 0x or 0X
    * Floating Constantts : 12.56, 0.5 ...
    * Single Character Constants : 'a', 'x' ... (No Double quotes like "a" or "x")
    * String Constants : "Jeman", "Jack" --> No Single quotes like 'Jeman' or 'Jack'
        * Ex: String constant : "Jenny". C will add a null Character constant ('\0') to the string to mark it's end.
              Hence, it will be stored as "Jenny\0" and it's length will be 4+2 = 6
    * Declaring constants in C : 
        * void main(){
            const int a = 10;
        }
        * #define PI 3.14 --> No space between '#' and 'define'.

Variables in C : 
    * int a = 10;
    * 'a' is the symbolic alias of the memory location where 10 is stored.
    * Declaration:
        * int a; --> sets a memory location's alias as 'a'
        * float a;
        * char a;
    * Initialization:
        * a = 10;
        * float b;
        * char c;
    * Variable names rules:
        * Allows : A-Z, a-z, 0-9 and '_'
        * Should start with alphabet or '_', not a digit.
        * case sensitive. ca != Ca != cA
        * U can't use reserved keywords.
        * No whitespace or special chars like #, @, $, !, %
        * Length <= 31

Identifiers and Keywords : 
    * 32 keywords.
    * Identifiers = Variable names

Data Types in C:

    * Data types help reverving adequate amount of memory to the variable depending on the type.
    * Primary Data Types:
        * int   
        * float
        * char
        * double
        * void
    * Derived Data Types:
        * Array
        * Structure
        * Union
        * Pointers
    * User defined Data Types:
        * Typedef
        * Enum
